# 飞书 → Get 笔记 Chrome 插件 · 团队安装使用指南

> 一键把任意飞书文档导入到你的 Get 笔记，作为 markdown 笔记保存，方便后续用 Get 笔记的 AI 二次加工 / 检索。

## 这个插件能做什么

- 在浏览器看任意飞书文档（`feishu.cn/docx/...` 或 `/wiki/...`），点一下按钮就能把内容当 markdown 灌入你的 Get 笔记
- 自动带上 `from-feishu` 标签，方便在 Get 笔记里筛选
- 保留标题、列表、代码块、引用、加粗/斜体/链接等格式
- Get 笔记路径不导图片；网页 / 公众号保存为飞书文档时会尝试把正文图片插入为飞书原生图片块

## 重要：飞书权限说明

**每个团队成员必须用自己的飞书账号登录一次。**

原因：
- 插件通过 OAuth 拿的是「你这个人」的 access_token
- **你能在浏览器里打开的飞书文档，插件就能导出；你看不见的，插件也看不见**
- 不存在 "管理员账号一登所有人共享" 的模式（这反而更安全，避免越权读取别人的私有文档）

换句话说，**插件不会让你看到原本看不到的文档**。安装它对飞书侧的权限边界是零增益的，只是把"看到→人工复制粘贴"变成了"看到→一键灌入 Get 笔记"。

## 安装前你需要

1. **Chrome** / Edge / 任意 Chromium 内核浏览器
2. **Get 笔记账号 + 会员**（OpenAPI 是会员功能）——在 [Get 笔记开放平台](https://www.biji.com/openapi) 自己创建一个应用获取 API Key
3. 你日常用的 **飞书账号**

## 安装步骤（5 分钟）

### 步骤 1：拿代码

向 Spin 索取插件目录（压缩包或 git 仓库），解压后会有这样的目录结构：

```
feishu-getnote/
  extension/        ← 你要选这个目录
    manifest.json
    popup.html
    ...
```

### 步骤 2：加载到 Chrome

1. 浏览器地址栏输入 `chrome://extensions` 回车
2. 右上角打开 **「开发者模式」** 开关
3. 左上角点 **「加载已解压的扩展程序」**
4. 选择 `feishu-getnote/extension/` 这个目录（注意：选 `extension/`，不是它的父目录）
5. 工具栏右上角出现一个蓝色方块图标 = 安装成功

### 步骤 3：申请 Get 笔记 API Key

1. 打开 [https://www.biji.com/openapi](https://www.biji.com/openapi)
2. 登录你的 Get 笔记账号（**需要会员**）
3. 创建一个应用，名称随意（比如 `MyFeishuImporter`）
4. 拿到两个值：
   - **API Key**（形如 `gk_live_xxxxxxxx...`）
   - **Client ID**（形如 `cli_xxxxxxxx...`）
5. 这两个值只存在你本机的浏览器 storage 里，不上传任何服务器

### 步骤 4：配置插件

1. 右键插件图标 → 选择 **「选项」**（或点图标 → 弹窗里点「设置」）
2. 填三样东西：

| 字段 | 值 |
|---|---|
| **Worker URL** | `https://lark-doc-proxy.spin-liu.workers.dev` |
| **Get 笔记 API Key** | 你刚拿到的 `gk_live_xxx` |
| **Client ID** | 你刚拿到的 `cli_xxx` |

3. 点 **「保存」**
4. 点 **「登录飞书」** 按钮 → 弹出飞书授权页 → 同意 → 状态显示 "已登录飞书" = 完成

> Worker URL 是团队共享的代理（Spin 部署的，藏了应用 secret），所有人填同一个值。

## 使用方法

1. 在 Chrome 里打开任意飞书文档：
   - `https://xxx.feishu.cn/docx/<token>`
   - `https://xxx.feishu.cn/wiki/<token>`
2. 点工具栏的插件图标
3. 在弹窗里点 **「导入到 Get 笔记」**
4. 等 2-5 秒（取决于文档长度），看到 ✓ **「已导入：<文档标题>」** 即成功
5. 打开 Get 笔记客户端，新笔记带 `from-feishu` 标签

## 常见问题

**Q：登录飞书后没自动回跳？**
A：浏览器拦了弹窗。设置里允许 `lark-doc-proxy.spin-liu.workers.dev` 弹窗，重试。

**Q：过几天突然提示 "session 失效"？**
A：refresh token 30 天过期。重新点「登录飞书」即可。

**Q：「Get 笔记写入失败」？**
A：先检查 API Key + Client ID 是否填对；如果是连续导入多篇被限流（Get 笔记 < 2 QPS），等一分钟再试。

**Q：导入后表格变成了 `<!-- table ... -->` 占位？**
A：第一版的已知边界。普通文字/列表/代码都能保留，复杂表格留待后续。可以临时方案：在飞书里把表格选中复制 → 手工补到 Get 笔记。

**Q：图片去哪了？**
A：导入 Get 笔记时仍会清理图片，避免第三方外链导致 Get 写入失败。保存为飞书文档时会尝试转存正文图片；如果图片站点反盗链，弹窗会显示插入失败数量。

**Q：我换电脑了还要重装吗？**
A：是。插件 + 配置（Get 笔记 Key + 飞书登录）都要在新浏览器重做一次。

**Q：API Key 安全吗？**
A：只存于你本机的 `chrome.storage.local`，不会上传到任何服务器（包括 Spin 的 Worker）。Worker 只代理飞书侧的事，完全不接触 Get 笔记的 Key。

**Q：能不能批量导一个 wiki 空间的所有文档？**
A：第一版不支持。需要的话告诉 Spin，可以做第二版。

## 出问题找谁

Spin。提供以下信息能加快排查：
1. 报错的截图或完整文字
2. 报错时浏览器地址栏的 URL（飞书文档 URL）
3. 浏览器版本（`chrome://version`）
